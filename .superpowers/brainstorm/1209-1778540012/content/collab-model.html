Collaboration Model

Scrivener's biggest weakness is solo-only. How live should Beehive Studio's collaboration be?

A

Real-time (Google Docs style)

Multiple cursors, live typing, presence indicators. Requires a CRDT or OT sync layer (e.g. Liveblocks, Yjs). High engineering cost but maximum differentiation from Scrivener.

B

Async collaboration (evolve v1 Hives)

Chapter ownership, submit-for-review, inline suggestions, comments. The existing Hive model but tightly integrated into the Studio workspace. Lower engineering cost, works well for co-authors with different schedules.

C

Hybrid — async core + real-time sessions

Async as the default (like Hives), plus optional live "writing sessions" where collaborators can see each other's presence. Best of both worlds, but scoped — real-time only during an active session, not always-on.
