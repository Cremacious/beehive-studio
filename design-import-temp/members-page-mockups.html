Members page — 3 design options

All three keep the same data (owner, roles, invites, capacity). They differ in how they organize it.

Option A

Stat strip + forum table

Stats up top (capacity progress, owner card, oldest member), tabbed control for view (All / By role / Pending invites), then a dense forum-table list. Most "admin dashboard." Invite affordances live behind a CTA → modal so the page stays clean.
