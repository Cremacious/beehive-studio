Notice: no more "Skip" button — the bio is already optional and "Continue" handles the empty case. Same treatment on step 3 ("Finish setup" replaces both buttons there).

Option A — Clickable indicator pills only

Reached pills (done state) become clickable. No explicit Back button in the footer. Risk: some users don't know pills are interactive — it's discoverable, not obvious.

Option B — "← Back" text button only

A small text link in the footer row, left of the primary CTA. Always linear — Back goes to immediately-previous step. Risk: from step 3 you'd click Back twice to reach step 1.

Option C — Both (recommended)

"← Back" for one-step-back muscle memory. Clickable pills for jumping directly to any reached step (e.g. step 3 → step 1 in one click). Costs ~30 lines of code total; covers both interaction styles.

  2. Step 3 label: Photo or Preferences (and if Preferences, what does the step collect?)
