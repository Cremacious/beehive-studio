01/12 Brief — Studio Shell

A writer's desk —
cream paper on warm walnut.

The studio shell is the room a novelist lives in for hours. Chris asked for cozy. Cozy doesn't mean soft-everything; it means a warm sheet of paper on a desk lit by a lamp — and a strong, quiet dark frame around it that lets the paper be the loudest thing in the room.

This document covers all persistent chrome (§§5.1–5.7 of the brief), in both editor modes, with every state. It also establishes the token system and depth language that Prompts 2 (specialized surfaces) and 3 (overlays & modes) will inherit.

01 Design rationale

The system at a glance.

Six decisions that the rest of the document is built on.

Palette · warm walnut + cream

Chrome lives at L 0.20–0.29, C 0.012, H 55° — a deep espresso-walnut, never slate. Paper sits at L 0.96, C 0.018, H 85° — ivory cream, perceptibly warm but not yellow. The contrast is the desk.

The old #141414 is replaced surface-by-surface. Brand yellow #FFC300 is preserved exactly — every other chrome value got a 5–10° hue rotation toward warm.

Depth · stacked-paper elevation

Every elevated surface carries three layers: a 1px inset white highlight (the leading edge of the page), a sharp 2–4px dark drop (the spine shadow), and a soft long blur (the room).

One scale, four levels — applied consistently to popovers, status pills, modals, toasts. Flatness is reserved for body text; everything tactile lifts.

Type · serif body, sans chrome

Comfortaa stays for branding and headings — its softness matches the cozy brief. Geist stays for UI body. Newsreader joins as the prose face inside the editor — an open optical serif that reads like a book at 18px.

Numerics use JetBrains Mono with old-style figures off (sprint timer, ISBN, file refs). 4 families, 4 jobs, no overlap.

Density · cozy, not bloated

Binder grew 240 → 264px, metadata 240 → 288px, binder row 28 → 36px. Toolbar height stays at 48 to keep the prose area generous on a 13" laptop.

Result: more air around every interaction without the writing surface getting smaller. The chrome feels heavier; it actually isn't.

Status palette · 5 harmonised hues

Chapter status sweeps from cool to warm as work progresses: Idea (cloud blue) → Outline (plum) → First Draft (warm yellow) → Revised (sage) → Final (terracotta).

All at chroma ≈ 0.08, lightness ≈ 0.72 — six hues that sit together without one screaming. The same chroma is reused for binder type indicators (§4).

Brand yellow · used sparingly, used loudly

Yellow appears in exactly five places: the active binder row, the unsaved-dot, the +Add button, premium badges, and active toolbar buttons. Everywhere else it's the soft 18% wash (--brand-soft).

Discipline matters: if everything is yellow, nothing is. The unsaved-dot has to jump at a writer mid-thought.

12 Handoff & open questions

For Prompts 2 & 3.

Tokens, depth, type, and the chrome/paper duality established here are inherited downstream. These are the things to carry forward — and the things to decide before Prompt 2.

What's locked from this brief
  • Token names + values (tokens.css).
  • Type pairing: Comfortaa · Geist · Newsreader · JetBrains Mono.
  • Elevation scale el-0 → el-4 + el-paper.
  • Chrome (warm walnut) vs canvas (paper / coffee) split.
  • 6 binder type colors · 5 status colors · 3 validation colors.
  • Popover, modal, toast, pill, input, button primitives.
  • Hive button placement (binder footer).
Open questions for Chris
  • Light editor mode is paper-only — does the chrome ever flip to a true light theme for accessibility users? (Recommendation: no, keep chrome dark; add a high-contrast variant of dark instead.)
  • Should the sprint timer offer a "blackout" Pomodoro mode that hides word count until the sprint ends? (Out of scope here; flag for Prompt 3.)
  • The corkboard cards above borrow the paper surface even when the editor is in dark mode — confirm that's desirable. (My pick: yes — the corkboard is a planning artifact, not the writing.)
  • Premium badge style: pill (current) vs subtle sparkle next to label — settle on one for consistency across Prompt 3 (export, history, analysis).
  • Font-size selector currently affects only prose. Should the toolbar offer a separate UI density toggle (cozy / standard / compact)? Hold for now.
